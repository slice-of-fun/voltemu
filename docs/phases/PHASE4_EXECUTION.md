# Phase 4 — UI Modernization Execution

This document tracks the execution of **Phase 4: UI Modernization** as defined in the project `ROADMAP.md`.

The primary goal of this phase is to build a cleaner, more modern, and more capable user interface across all platforms. Due to the lack of a live compiler in the current workspace, tasks focusing on aesthetic changes (CSS/QSS) and safe static Qt adjustments will be prioritized, while heavy C++ view logic changes may be audited or deferred.

## Step 1: Game Library

**Objective:** Modernize the game list into a feature-rich library view.

- [ ] Grid and list view modes
- [ ] Sort by: name, last played, playtime, rating
- [ ] Filter by: genre, publisher, region, installed status
- [ ] Game artwork display (box art, banner, screenshot)
- [ ] Recently played section
- [ ] Favorites system
- [ ] Search with instant results
- [ ] Bulk game management

## Step 2: Settings Interface

**Objective:** Overhaul the configuration screens for clarity and ease of use.

- [ ] Categorized settings with search
- [ ] Per-setting help text and documentation
- [ ] Settings validation with clear error messages
- [ ] Import / export settings profiles
- [ ] Reset individual settings or sections to default
- [ ] Visual diff between current and default settings

## Step 3: Controller Configuration

**Objective:** Make input binding highly visual and intuitive.

- [ ] Visual controller mapper with button visualization
- [ ] Support for multiple controller profiles
- [ ] Per-game controller bindings
- [ ] Gyroscope configuration
- [ ] Rumble configuration
- [ ] Controller test interface

## Step 4: Game Management

**Objective:** Give users more control over individual game files and data.

- [ ] Game properties panel (metadata, paths, settings override)
- [ ] Custom game entries (for XCI / NSP from any directory)
- [ ] Game notes / personal tags
- [ ] Playtime tracking
- [ ] Launch history

## Step 5: Update System

**Objective:** Make emulator and game updates frictionless.

- [ ] In-app update checker
- [ ] Changelog viewer
- [ ] DLC and update management per game
- [ ] Firmware management interface

## Step 6: Logging & Debug Tools

**Objective:** Modernize the developer and debugging UI.

- [ ] Filterable log viewer (by level, module, game)
- [ ] Log export
- [ ] Performance overlay (FPS, frame time, GPU usage)
- [ ] GPU debugger integration hooks
- [ ] Shader viewer (debug builds)
