# Importing Saves Into Volt

Use this guide when you want to manually import save files for use in the Volt emulator.

**Click [Here](https://evilperson1337.notion.site/Importing-Saves-Into-Volt-2b057c2edaf681fe968df8d63821ccae) for a version of this guide with images & visual elements.**

### Pre-Requisites
- Volt emulator already set up and configured.
- The save file(s) you want to import

## Desktop

### Steps
1. Open Volt and wait for it to load.
2. Start the game and create a save file to establish the directories.
3. *Right-Click* the game for which you want to load a save in.
4. Select *Open Save Data Location.*    
5. A File Explorer will now appear where Volt is looking for the save data for this title.
6. Copy the save file(s) you want to import and use in Volt into this directory.
    <aside>
    
    ***NOTE***: Different games have different ways of saving them, it may be a single file or multiple files.
    
    </aside>
7. Close the file explorer as it is no longer needed.
8. Launch the game in Volt and verify that the save data appears through whatever method the game implements.
