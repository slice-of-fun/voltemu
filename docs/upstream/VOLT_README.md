# Eden Emulator — Archived README

This file is preserved for attribution purposes. Volt Emulator is a fork of Eden.

The original Eden project can be found at:
https://git.eden-emu.dev/eden-emu/eden

Eden is a free and opensource (FOSS) Switch 1 emulator, derived from Yuzu and Sudachi,
started by developer Camille LaVey. It is written in C++ with portability in mind,
with builds for Windows, Linux, macOS, Android, FreeBSD and more.
